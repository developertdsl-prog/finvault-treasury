# Changelog - FinVault-Treasury

All notable changes to this project are documented chronologically in accordance with [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2026-10-27
### Added
- Enterprise-grade Zero-Balance & Target-Balance Liquidity Pooling engine with automated sweep execution.
- Cross-Border Multi-Currency FX Hedging module calculating forward contracts, mark-to-market valuations, and Value-at-Risk (VaR).
- High-throughput 3-Way Automated Reconciliation Engine matching ISO 20022 camt.053 statements against internal ERP ledgers.
- ISO 20022 pain.001 and pain.002 compliant payment instruction synthesizer and XML validator.
- Full React 18 Treasury Terminal Console with multi-currency balance graphs, live FX terminal, and sweep executor.

## [0.7.0] - 2026-09-18
### Added
- Dynamic Yield Optimizer allocating operational funds between overnight reverse repo and high-yield deposits.
- Sanctions and AML screening audit log with immutable cryptographic hashes.

## [0.4.0] - 2026-08-14
### Added
- Multi-entity corporate hierarchy model supporting subsidiary accounts and intercompany lending registers.
- Automated rate limiter and strict double-entry ledger verification.

## [0.1.0] - 2026-07-01
### Initial
- Core treasury repository scaffolding, Mongoose financial data models, and Docker orchestration configuration.
